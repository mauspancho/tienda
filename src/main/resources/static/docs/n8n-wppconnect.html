WPPConnect y n8n

Genera una credencial en Administración > WhatsApp. En n8n usa autenticación Bearer con el token mostrado una sola vez.

Operaciones

GET  /api/integrations/v1/{tenantCode}/whatsapp/status
GET  /api/integrations/v1/{tenantCode}/whatsapp/groups
POST /api/integrations/v1/{tenantCode}/whatsapp/send

Texto

{"phone":"120363000000000000@g.us","isGroup":true,"message":"Productos disponibles"}

Imagen o PDF

Envía multipart/form-data con phone, isGroup, caption y file. Se aceptan PNG, JPEG, WebP y PDF de hasta 10 MB.

Seguridad

No compartas el token. Revócalo desde el panel si deja de utilizarse. El código de tienda no reemplaza la autenticación.
